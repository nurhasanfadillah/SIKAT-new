<objective>
## Goal
Ganti semua penggunaan `Math.random()` di server.ts dengan `crypto.randomBytes` dari Node.js built-in crypto module — untuk session tokens dan ID generation.

## Purpose
`Math.random()` tidak kriptografis — dapat diprediksi. Session tokens yang lemah memungkinkan session hijacking. `crypto.randomBytes` menggunakan CSPRNG (Cryptographically Secure Pseudo-Random Number Generator).

## Output
- `server.ts` diupdate: import `randomBytes` dari `crypto`, semua 7 penggunaan `Math.random().toString(36)` diganti
</objective>

@server.ts
</context>
