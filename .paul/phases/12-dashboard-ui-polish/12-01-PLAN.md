## AC-1: Progress bar edge case aman
```gherkin
Given kasBalance bernilai 0
When dashboard merender kedua stat cards
Then progress bar "Dana Talang Aktif" menampilkan 100% jika ada talang (atau 0% jika tidak ada)
  AND progress bar "Kapasitas Sisa" menampilkan 0%
  AND tidak ada width CSS yang bernilai negatif atau undefined
```

## AC-2: Warna nominal transaksi akurat
```gherkin
Given transaksi Kas Pengeluaran atau Talang Pelunasan ada di daftar terkini
When dashboard merender transaction list
Then nominal transaksi tersebut berwarna text-rose-400 (merah)
  AND transaksi Kas Pemasukan dan Talang Baru tetap berwarna text-brand-500 (hijau)
  AND Talang Transfer tetap berwarna text-slate-100 (neutral)
```

## AC-3: Tidak ada text overflow di stat cards dan transaction metadata
```gherkin
Given nominal currency panjang di account cards
  OR kategori transaksi yang panjang di metadata list
When dashboard merender
Then text terpotong dengan ellipsis (truncate) tanpa overflow keluar container
  AND badge "Aktif"/"Aman" tidak tertutup oleh nilai currency
```

## AC-4: Polling interval dioptimalkan
```gherkin
Given dashboard terbuka di browser
When background polling aktif
Then interval antar API call adalah 30 detik (bukan 5 detik)
```

## AC-5: Elemen dekoratif tidak mengganggu screen reader
```gherkin
Given halaman dashboard merender
When screen reader atau accessibility tree di-inspect
Then blur decorative divs di hero card memiliki aria-hidden="true"
  AND tidak muncul sebagai elemen interaktif atau bermakna
```

    **A1 — Progress bar edge case (baris ~120 dan ~135):**

    Ganti kedua inline style calculation dengan variabel terpisah. Letakkan setelah kalkulasi `saldoBersih` (baris ~46), sebelum return statement:

    ```tsx
    // Tambahkan setelah: const saldoBersih = kasBalance - totalTalangAktif;
    const talangPct = kasBalance > 0
      ? Math.min(100, (totalTalangAktif / kasBalance) * 100)
      : (totalTalangAktif > 0 ? 100 : 0);
    const saldoPct = kasBalance > 0
      ? Math.min(100, Math.max(0, (saldoBersih / kasBalance) * 100))
      : 0;
    ```

    Lalu ganti inline style di progress bars:
    ```tsx
    // Baris ~120 — ganti
    style={{ width: `${Math.min(100, (totalTalangAktif / (kasBalance || 1)) * 100)}%` }}
    // Menjadi:
    style={{ width: `${talangPct}%` }}

    // Baris ~135 — ganti
    style={{ width: `${Math.min(100, (saldoBersih / (kasBalance || 1)) * 100)}%` }}
    // Menjadi:
    style={{ width: `${saldoPct}%` }}
    ```
