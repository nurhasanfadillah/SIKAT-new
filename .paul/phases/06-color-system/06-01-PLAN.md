<objective>
## Goal
Definisikan centralized semantic color token system di `src/index.css` (`@theme`) dan `src/lib/tokens.ts`, lalu migrasikan 5 UI components + SplashScreen dari light-mode defaults ke dark token equivalents.

## Purpose
UI components saat ini (`button`, `input`, `tabs`, `card`) menggunakan hardcoded Tailwind light-mode colors (`bg-white`, `bg-slate-100`, `border-slate-300`, `text-slate-950`) yang tidak sesuai dengan dark theme SIKAT. `SplashScreen` menggunakan `bg-blue-600` yang off-brand. Plan ini menjadi fondasi token yang akan digunakan seluruh 12 file di Phase 06.

## Output
- `src/index.css` — `@theme` diperluas dengan 25 color tokens (brand, surface, status, text)
- `src/lib/tokens.ts` — JS-facing constants untuk recharts dan Framer Motion
- 5 UI components + SplashScreen dimigrasikan ke dark token utilities
</objective>
