<objective>
## Goal
Migrasi semua hardcoded hex values dan non-token color classes di Dashboard.tsx, Kas.tsx, Talang.tsx, dan Laporan.tsx ke semantic tokens dari Plan 06-01. Update recharts fills di Laporan.tsx dari hardcoded hex ke tokens.ts constants.

## Purpose
Keempat halaman ini adalah isi utama aplikasi — setelah plan ini, seluruh app (shell + auth + pages) sepenuhnya konsisten dengan token system. Laporan.tsx membutuhkan perhatian khusus karena recharts Bar fills menerima raw hex string (bukan Tailwind utilities), sehingga perlu import dari tokens.ts.

## Output
- Dashboard.tsx — hero gradient pakai hero-* tokens; semua emerald-* → brand-*; card backgrounds pakai surface-card
- Kas.tsx — semua emerald-* → brand-*; CTA button dan form pakai brand tokens; ledger card backgrounds pakai surface-card
- Talang.tsx — emerald-* sisanya (pelunasan button, settlement badge, notice box) → brand-*
- Laporan.tsx — emerald-* dan hex → tokens; recharts fills via tokens.ts import
</objective>
