<objective>
## Goal
Migrasi semua hardcoded hex values dan non-token Tailwind color classes di `Layout.tsx` dan `Login.tsx` ke semantic tokens yang didefinisikan di Plan 06-01, sekaligus memperbaiki 2 WCAG violations kritis di kedua file.

## Purpose
Layout.tsx adalah shell utama aplikasi — semua halaman berjalan di dalamnya. Login.tsx adalah entry point. Keduanya masih penuh dengan `#060a13`, `#0c1221`, `bg-[#00e5a3]`, `text-emerald-*` dll. Setelah plan ini, seluruh shell + auth layer konsisten dengan token system.

## Output
- `Layout.tsx` — semua 14 inline hex diganti token; nav active state pakai `brand-*`; WCAG nav label fix
- `Login.tsx` — semua 5 inline hex diganti token; input overrides perbaiki `focus:border-emerald-500/50` → `focus:border-brand-500`; submit button pakai `brand-*`
</objective>
