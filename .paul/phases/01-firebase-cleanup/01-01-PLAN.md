<objective>
## Goal
Hapus semua artifact Firebase yang tidak terpakai dari proyek SIKAT-new: uninstall package, hapus config files, dan update dokumentasi codebase.

## Purpose
Firebase tidak digunakan dalam kode sumber aplikasi sama sekali — tidak ada import di `src/` maupun di `server.ts`. File-file ini adalah sisa dari template Google AI Studio dan hanya menambah noise + ukuran `node_modules` tanpa manfaat apapun. Membersihkannya menjaga codebase tetap minimal dan tidak menyesatkan kontributor baru.

## Output
- `firebase-applet-config.json` dihapus
- `firebase-blueprint.json` dihapus
- `package.json` tidak lagi mengandung `"firebase"` dependency
- `node_modules` tidak lagi mengandung Firebase packages
- `.paul/codebase/INTEGRATIONS.md` dan `STRUCTURE.md` diperbarui
</objective>

  <files>package.json, package-lock.json</files>
  <action>

    ```

    - Menghapus "firebase" dari `dependencies` di package.json

    ```
    npm run lint
