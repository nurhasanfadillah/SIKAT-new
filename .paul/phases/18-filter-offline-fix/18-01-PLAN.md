<task type="auto">
  <name>Task 1: Fix Workbox navigateFallback di vite.config.ts</name>
  <files>vite.config.ts</files>
  <action>
    Di blok `workbox` dalam VitePWA config:

    1. Ubah `navigateFallback: '/offline.html'` → `navigateFallback: '/index.html'`
       Alasan: '/index.html' adalah SPA fallback yang benar untuk React Router.
       '/offline.html' menyebabkan semua SPA routes yang tidak ada sebagai file fisik
       di-serve sebagai halaman offline, meskipun user masih online.

    2. Ganti `navigateFallbackAllowlist` dengan `navigateFallbackDenylist`:
       ```
       navigateFallbackDenylist: [/^\/api\//, /^\/offline\.html/],
       ```
       Alasan: Denylist lebih safe — exclude hanya yang tidak boleh di-handle SPA (/api/ dan
       offline.html itu sendiri). Allowlist lama sudah tidak cocok setelah navigateFallback
       diubah ke index.html.

    3. Hapus baris `navigateFallbackAllowlist` sepenuhnya dan ganti dengan `navigateFallbackDenylist`.

    Hasil akhir blok workbox:
    ```javascript
    workbox: {
      globPatterns: ['**/*.{js,css,html,ico,png,svg,woff,woff2}'],
      navigateFallback: '/index.html',
      navigateFallbackDenylist: [/^\/api\//, /^\/offline\.html/],
      runtimeCaching: [
        {
          urlPattern: /^\/api\//,
          handler: 'NetworkFirst',
          options: {
            cacheName: 'api-cache',
            networkTimeoutSeconds: 10,
            expiration: {
              maxEntries: 50,
              maxAgeSeconds: 300
            }
          }
        }
      ]
    }
    ```
  </action>
  <verify>Baca vite.config.ts dan konfirmasi navigateFallback: '/index.html' dan navigateFallbackDenylist ada; navigateFallbackAllowlist tidak ada.</verify>
  <done>AC-1 satisfied: SPA routes tidak lagi di-route ke offline.html sebagai navigateFallback</done>
</task>

<task type="auto">
  <name>Task 2: Fix offline.html — retry logic + warna design system</name>
  <files>public/offline.html</files>
  <action>
    Perbaiki 3 hal di offline.html:

    **A. Fix retry button onclick** (baris ~49):
    Ubah: `onclick="window.location.reload()"`
    Jadi: `onclick="window.location.href = '/'"` 
    Alasan: reload() me-reload offline.html itu sendiri; href='/' navigate ke root app.

    **B. Fix auto-reconnect handler** (script tag di bawah):
    Ubah: `window.location.reload();`
    Jadi: `window.location.href = '/';`
    Alasan: sama — reconnect harus navigate ke app, bukan loop ke offline.html.

    **C. Fix warna design system** (CSS style block):
    - `background: #0f172a` → `background: #050811` (sesuai app background)
    - `.retry-btn { background: #2563eb }` → `background: #00e5a3` (brand-500)
    - `.retry-btn { color: #fff }` → `color: #050811` (text-inverse karena bg brand terang)
    - `.retry-btn:hover { background: #1d4ed8 }` → `background: #00cc90`

    Jangan ubah struktur HTML, font, ukuran, atau konten teks.
  </action>
  <verify>Baca public/offline.html dan konfirmasi: (1) button onclick = href='/', (2) window.online handler = href='/', (3) background #050811, (4) retry-btn background #00e5a3 dengan color #050811.</verify>
  <done>AC-2 + AC-3 satisfied: retry dan auto-reconnect navigate ke /, warna sesuai design system</done>
