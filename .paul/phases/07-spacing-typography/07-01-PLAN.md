<objective>
## Goal
Definisikan 5 custom text-size utilities di `@theme` (nano/micro/label/body/value), lalu ganti semua arbitrary font sizes yang redundan di seluruh aplikasi dengan class semantik tersebut.

## Purpose
App saat ini memiliki 15+ arbitrary font sizes (`text-[8px]` s/d `text-[18px]`) tanpa skala yang terdefinisi. `text-xs` dan `text-[12px]` dipakai bergantian untuk hal yang sama. Dengan type scale semantik, tiap developer tahu kapan harus pakai `text-label` vs `text-body` tanpa harus menghitung px.

## Output
- `src/index.css`: 5 custom text utilities ditambahkan ke `@theme`
- 7 file `.tsx`: semua arbitrary sizes yang ter-mapping diganti ke class semantik
</objective>

<task type="auto">
  <name>Task 1: Tambahkan custom text-size tokens ke @theme di index.css</name>
  <files>src/index.css</files>
  <action>
    Di dalam `@theme { }` block yang sudah ada, tambahkan 5 font-size tokens baru setelah bagian `--font-mono`:

    ```css
    /* ── Type Scale ──────────────────────────────────── */
    --text-nano:  0.5625rem;   /* 9px  — badge, pill, legend */
    --text-micro: 0.625rem;    /* 10px — label, caption, metadata */
    --text-label: 0.6875rem;   /* 11px — form label, nav item, card label */
    --text-body:  0.75rem;     /* 12px — list item, description, form input */
    --text-value: 0.8125rem;   /* 13px — section header secondary, card value */
    ```

    Tailwind v4 akan otomatis generate class `text-nano`, `text-micro`, `text-label`, `text-body`, `text-value` dari variabel `--text-*` di @theme.

    Jangan tambahkan @utility block — @theme saja cukup untuk font-size di Tailwind v4.
    Jangan ubah font-family atau variabel lain yang sudah ada.
  </action>
  <verify>Grep `--text-nano` di src/index.css → muncul 1 hasil di dalam @theme block</verify>
  <done>AC-1 satisfied: 5 token terdefinisi di @theme</done>
</task>

<task type="auto">
  <name>Task 2: Ganti arbitrary font sizes dengan class semantik di semua halaman</name>
  <files>
    src/components/Layout.tsx,
    src/pages/Login.tsx,
    src/pages/Dashboard.tsx,
    src/pages/Kas.tsx,

    src/pages/Laporan.tsx
  </files>
  <action>
    Terapkan mapping berikut secara konsisten di semua file — replace setiap arbitrary size dengan class semantik yang sesuai:

    MAPPING WAJIB (harus diganti):
    - `text-[9px]`   → `text-nano`
    - `text-[9.5px]` → `text-micro`   (hanya di Laporan.tsx L87)
    - `text-[10px]`  → `text-micro`
    - `text-[11px]`  → `text-label`
    - `text-[12px]`  → `text-body`
    - `text-xs`      → `text-body`    (text-xs = 12px, semantik identik dengan text-body)
    - `text-[13px]`  → `text-value`

    JANGAN GANTI (biarkan arbitrary):
    - `text-[8px]`   — hanya untuk legend/progress annotation, terlalu kecil untuk token
    - `text-[15px]`  — dipakai jarang, tidak perlu token
    - `text-[18px]`  — dipakai jarang, tidak perlu token
    - `text-sm`, `text-xl`, `text-2xl`, `text-3xl` — Tailwind standard sizes, keep as-is

    PERHATIAN:
    - Ganti semuanya termasuk yang di dalam string template literal seperti `${isActive ? 'text-[11px]' : 'text-[11px]'}`
    - Pastikan ganti semua occurrence di setiap file, bukan hanya yang pertama
    - Jangan ubah logika conditional atau className lainnya — hanya ubah nama class font size

    Contoh benar:
    SEBELUM: `className="text-[11px] font-bold text-slate-400"`
    SESUDAH: `className="text-label font-bold text-slate-400"`
  </action>
