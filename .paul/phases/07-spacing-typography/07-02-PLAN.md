<objective>
## Goal
Standardisasi card padding ke 3-tier yang konsisten (p-5/p-4/p-3), section spacing ke `space-y-4`, dan grid/item gaps ke skala yang seragam.

## Purpose
Saat ini ada 5 varian padding card (`p-2.5`, `p-3`, `p-3.5`, `p-4`, `p-5`) tanpa aturan yang jelas. Card bertipe sama memiliki padding berbeda di halaman yang berbeda. Dengan 3-tier sistem, developer langsung tahu: hero card → p-5, standard card → p-4, compact card → p-3.

## Output
- 5 file halaman + Layout.tsx: padding dan gap distandarisasi ke 3-tier system
</objective>

## AC-1: 3-tier card padding konsisten
```gherkin

When melihat card components
Then hero/primary cards pakai p-5, standard cards pakai p-4, compact stat cards pakai p-3 — tidak ada p-2.5 atau p-3.5 di card content
```

## AC-2: Section spacing seragam
```gherkin
Given top-level container di setiap halaman
When memeriksa className space-y-*
Then semua top-level page container pakai space-y-4 (tidak ada space-y-5 di level tertinggi)
```

## AC-3: Item gap konsisten
```gherkin
Given 2-col grid di semua halaman
When memeriksa gap-* pada grid container
Then semua 2-col stat grids pakai gap-3, bukan gap-2 atau gap-2.5
```
