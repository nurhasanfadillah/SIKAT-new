<objective>
## Goal
Uninstall tiga dependensi yang terinstall tapi tidak digunakan dalam kode sumber: `better-auth`, `better-sqlite3`, dan `@google/genai`.

## Purpose
Ketiga package ini ada di `package.json` sebagai artifact dari template Google AI Studio, namun tidak ada satu pun import atau penggunaan di `src/` maupun `server.ts`. Menghapusnya mengurangi ukuran `node_modules`, mengurangi attack surface, dan menghilangkan potensi kebingungan bagi kontributor baru.

## Output
- `package.json` bebas dari `better-auth`, `better-sqlite3`, `@google/genai`
- `node_modules` tidak lagi mengandung ketiga package tersebut
- `.env.example` dibersihkan dari variabel yang hanya relevan untuk package yang dihapus
- `.paul/codebase/INTEGRATIONS.md` diperbarui
</objective>

  <files>package.json, package-lock.json</files>
  <action>
    Jalankan satu perintah untuk uninstall ketiganya sekaligus:
    ```
    npm uninstall better-auth better-sqlite3 @google/genai
    ```

    Perintah ini akan:
    - Menghapus ketiga package dari `dependencies` di package.json
    - Menghapus entri terkait dari package-lock.json
    - Menghapus dari node_modules (beserta sub-dependencies eksklusif mereka)

    ```
    npm run lint
    ```

    Jangan uninstall package lain. Jangan hapus `@types/better-sqlite3` atau
    `@types/pg` — cek dulu apakah mereka masih relevan setelah uninstall.
  </action>
