<objective>
## Goal
Fix 5 bug dan inkonsistensi di header aplikasi pada mobile view: theme color salah (biru → teal), iOS PWA status bar putih di atas app gelap, tidak ada safe-area-inset-top padding, header overflow di 360px Android, dan `text-[15px]` arbitrary di luar type scale.

## Purpose
Header adalah elemen pertama yang dilihat user saat membuka app. Theme color salah (`#2563EB`) terlihat di Android Chrome tab dan PWA splash screen — langsung kontradiksi dengan brand teal yang sudah dibangun Phase 06. iOS PWA terlihat "webby" dengan status bar putih di atas app dark navy. Header overflow di HP entry-level (360px, umum di target market sekolah) membuat role badge dan logout button tidak tampil.

## Output
- `vite.config.ts`: `theme_color` dan `background_color` diupdate
- `index.html`: `theme-color`, `viewport-fit=cover`, `status-bar-style: black-translucent`
- `src/components/Layout.tsx`: safe-area padding, flex shrink, `text-[15px]` dihapus
</objective>
