- `src/App.tsx` — di-update: SplashScreen di-render sebagai layer overlay terluar

<task type="auto">
  <name>Buat src/components/SplashScreen.tsx dengan Framer Motion</name>
  <files>src/components/SplashScreen.tsx</files>
  <action>
    Buat file baru `src/components/SplashScreen.tsx`:

    ```tsx
    import { motion, AnimatePresence } from 'motion/react';

    interface SplashScreenProps {
      visible: boolean;
    }

    export function SplashScreen({ visible }: SplashScreenProps) {
      return (
        <AnimatePresence>
          {visible && (
            <motion.div
              initial={{ opacity: 1 }}
              exit={{ opacity: 0 }}
              transition={{ duration: 0.6, ease: 'easeOut' }}
              className="fixed inset-0 z-50 flex flex-col items-center justify-center bg-blue-600"
            >
              <img
                src="/pwa-512x512.png"
                alt="SIKAT"
                className="w-24 h-24 mb-6 rounded-2xl shadow-lg"
              />
              <p className="text-white text-2xl font-bold tracking-widest">SIKAT</p>
              <p className="text-blue-200 text-sm mt-2 tracking-wide">
                Sistem Kas Sekolah dan Talang
              </p>
            </motion.div>
          )}
        </AnimatePresence>
      );
    }
    ```

    Catatan penting:
    - Import dari `'motion/react'` (bukan 'framer-motion' — package yang terinstall adalah `motion`)
    - `AnimatePresence` wajib ada agar `exit` animation berjalan saat `visible` jadi false
    - `z-50` memastikan splash di atas semua konten
    - `fixed inset-0` cover seluruh viewport
    - Jangan tambahkan logic timer di sini — itu tanggung jawab App.tsx
  </action>
  <verify>
    1. `npx tsc --noEmit` → tidak ada error TypeScript
    2. Read file dan konfirmasi `AnimatePresence`, `motion.div`, `exit={{ opacity: 0 }}` ada
  </verify>

<task type="auto">
  <name>Integrasikan SplashScreen di src/App.tsx</name>
  <files>src/App.tsx</files>
  <action>
    Update `src/App.tsx` untuk mount SplashScreen sebagai overlay terluar:

    1. Tambah import di bagian atas (setelah import yang sudah ada):
       ```tsx
       import { useState, useEffect } from 'react';
       import { SplashScreen } from './components/SplashScreen';
       ```

    2. Di dalam function `App()`, sebelum `return`, tambah:
       ```tsx
       const [showSplash, setShowSplash] = useState(true);

       useEffect(() => {
         const timer = setTimeout(() => setShowSplash(false), 2500);
         return () => clearTimeout(timer);
       }, []);
       ```

    3. Di return statement, wrap seluruh JSX yang ada dengan Fragment dan tambah SplashScreen:
       ```tsx
       return (
         <>
           <SplashScreen visible={showSplash} />
           <AuthProvider>
             <FeedbackProvider>
               <Router>
                 <Routes>
                   ...existing routes...
                 </Routes>
               </Router>
             </FeedbackProvider>
           </AuthProvider>
         </>
       );
       ```

    Jangan ubah: ProtectedRoute, routes, AuthProvider, FeedbackProvider, Router structure.

    `useState(true)` → splash tampil saat load.
    `setTimeout 2500ms` → setelah 2.5 detik, setShowSplash(false) → AnimatePresence trigger exit animation (600ms fade).
    `return () => clearTimeout(timer)` → cleanup jika component unmount (React Strict Mode safe).
  </action>
