<objective>
## Goal
Ganti 3 icon placeholder solid blue dengan icon set lengkap berbasis SVG custom (ledger buku + koin), generate semua ukuran PWA via @vite-pwa/assets-generator, dan update manifest + index.html dengan brand color.

## Purpose
Icon placeholder (#2563EB solid) tidak representatif untuk app keuangan sekolah. Dengan icon yang relevan dan brand color yang konsisten di manifest, Android native splash otomatis ter-branding saat PWA di-install. Ini juga menyiapkan icon untuk Plan 05-02 (SplashScreen component).

## Output
- `public/logo.svg` — sumber icon SVG (ledger book + coin, biru)
- `public/pwa-64x64.png`, `pwa-192x192.png`, `pwa-512x512.png` — icon set di-generate
- `public/maskable-icon-512x512.png`, `public/apple-touch-icon-180x180.png` — maskable + iOS
- `pwa-assets.config.ts` — konfigurasi generator
- `vite.config.ts` — manifest icons + colors di-update
- `index.html` — theme-color + apple-touch-icon di-update
- Hapus: `public/pwa-maskable-512x512.png` (lama), `public/manifest.json` (stale)
</objective>

<task type="auto">
  <name>Install @vite-pwa/assets-generator + generate semua icon sizes</name>
  <files>package.json, pwa-assets.config.ts</files>
  <action>
    1. Install dev dependency:
       ```bash
       npm install -D @vite-pwa/assets-generator
       ```

    2. Buat `pwa-assets.config.ts` di root project:
       ```ts
       import { defineConfig, minimal2023Preset } from '@vite-pwa/assets-generator/config'

       export default defineConfig({
         preset: minimal2023Preset,
         images: ['public/logo.svg']
       })
       ```

    3. Tambahkan script di `package.json` (dalam block "scripts", setelah "vercel-build"):
       ```json
       "pwa:assets": "pwa-assets-generator --config pwa-assets.config.ts"
       ```

    4. Jalankan generator:
       ```bash
       npm run pwa:assets
       ```

    5. Hapus file lama yang tidak lagi dipakai:
       ```bash
       rm -f public/pwa-maskable-512x512.png
       rm -f public/manifest.json
       ```

    Jangan ubah: workbox config, registerType, devOptions di vite.config.ts.
  </action>
  <verify>
    1. `ls public/pwa-64x64.png public/pwa-192x192.png public/pwa-512x512.png` → ketiganya ada
    2. `ls public/maskable-icon-512x512.png public/apple-touch-icon-180x180.png public/favicon.ico` → semua ada
    3. `ls public/pwa-maskable-512x512.png 2>/dev/null || echo "deleted"` → "deleted"

  </verify>
