## Goal
Fix 5 UI issues di halaman Kas Rekap: 1 bug kritis (invalid color class), 2 inkonsistensi visual terhadap Dashboard, 1 empty state yang misleading, dan 1 accessibility gap.

## Purpose
Setelah Phase 12 memperbaiki Dashboard, Kas Rekap masih memiliki class `text-rose-450` yang tidak valid (warna Out tidak muncul), warna nominal Pengeluaran yang tidak konsisten dengan konvensi rose=outgoing, dan empty state yang tidak membedakan kondisi "filter aktif" vs "benar-benar kosong". Fix ini membawa Kas Rekap ke standar visual yang sama dengan Dashboard.

- `src/pages/Kas.tsx` — 5 targeted changes
- `.paul/phases/13-kas-rekap-ui-polish/13-01-SUMMARY.md`

## AC-1: "Out (Bulan ini)" Renders Rose
```gherkin
Given halaman Kas Rekap sudah di-load dengan data
When user melihat summary card "Out (Bulan ini)"
Then nilai pengeluaran bulan ini ditampilkan dengan warna rose-400 (bukan putih default)
```

## AC-2: Nominal Pengeluaran Rose di Transaction List
```gherkin
Given halaman Kas Rekap memiliki transaksi Pengeluaran
When user melihat daftar transaksi di ledger
Then nominal Pengeluaran berwarna rose-400 (konsisten dengan konvensi Dashboard)
  And nominal Pemasukan tetap berwarna brand-500 (tidak berubah)
```

## AC-3: Spinner Loading Konsisten dengan Dashboard
```gherkin
Given halaman Kas Rekap sedang loading data
When spinner muncul
Then spinner track berwarna white/10 (bukan brand-500/30)
  And spinner tip tetap brand-500
```

## AC-4: Empty State Pesan Kontekstual
```gherkin
Given daftar transaksi dalam kondisi kosong
When filteredKas.length === 0 AND kas.length > 0 (ada data tapi ter-filter)
Then pesan: "Tidak ada transaksi yang sesuai filter."

When filteredKas.length === 0 AND kas.length === 0 (benar-benar kosong)
Then pesan: "Belum ada transaksi terekam."
```

## AC-5: Icon Container Dekoratif Punya aria-hidden
```gherkin
Given transaction list item dengan icon TrendingUp/TrendingDown
When screen reader menelusuri halaman
Then container div icon (col-start-1 col-end-2) memiliki aria-hidden="true"
  And informasi arah transaksi tetap conveyed via warna nominal dan teks
```
