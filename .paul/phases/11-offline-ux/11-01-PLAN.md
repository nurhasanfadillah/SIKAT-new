<objective>
## Goal
Tambahkan auto-reconnect + tombol "Coba Lagi" ke `offline.html`, dan perbaiki z-index `ReloadPrompt` agar tidak tertutup navbar.

## Purpose
Saat ini user yang offline harus refresh manual — tidak ada notifikasi ketika koneksi kembali. Ini UX gap kritis untuk PWA mobile. ReloadPrompt (update notification) juga tidak terlihat karena tertutup navbar (`z-30` vs `z-40`).

## Output
- `public/offline.html` — ditambah button retry + script listener `online` event
- `src/components/ReloadPrompt.tsx` — z-index dinaikkan dari `z-30` ke `z-50`
</objective>
