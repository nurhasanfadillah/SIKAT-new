<objective>
## Goal
Fix dua bug layout mobile: (1) viewport naik saat keyboard muncul ketika edit, (2) bottom nav menutupi konten saat scroll mentok di Kas Rekap dan Dana Talang.

## Purpose
Keyboard viewport bug membuat UX edit sangat buruk di mobile — seluruh UI naik dan muncul ruang kosong di bawah. Bottom nav overlap membuat item terakhir di transaction list tidak bisa dibaca tanpa scroll extra. Kedua bug ini harus diselesaikan sebelum card redesign (17-02, 17-03) agar baseline layout stabil.

## Output
- `Layout.tsx` — `h-dvh` → `h-svh`, `min-h-dvh` → `min-h-svh`
- `Kas.tsx` — hapus `max-h-[500px] overflow-y-auto` dari transaction list wrapper
- `Talang.tsx` — hapus `${showForm ? 'max-h-[300px]' : 'max-h-[500px]'} overflow-y-auto` dari transaction list wrapper
</objective>
