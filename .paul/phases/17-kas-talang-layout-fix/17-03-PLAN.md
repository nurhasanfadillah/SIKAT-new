<acceptance_criteria>

## AC-1: Kolom 1 card menjadi 2-row (tanggal + akun tag)
```gherkin
Given card transaksi Talang ditampilkan
When user melihat kolom kiri card
Then baris 1 = tanggal (dd/MM), baris 2 = akun badge berwarna (Jisoi/Rakka/Shae)
  AND icon transaksi (ArrowUpRight/ArrowDownLeft/ArrowLeftRight) tidak tampil di card summary
```

## AC-2: Card clickable — expand/collapse accordion
```gherkin
Given card transaksi Talang dalam kondisi collapsed
When user mengklik card
Then expanded area muncul dengan animasi height 0→auto (AnimatePresence)
  AND ChevronDown icon berotasi 180° di kolom 3 baris 2
  AND hanya satu card yang expand sekaligus (expandedId accordion)

Given card sedang dalam mode edit (editingId === t.id)
When user mengklik card
Then klik tidak memicu expand/collapse (guard: if editingId === t.id return)
```

## AC-3: Expanded area menampilkan detail + tombol aksi
```gherkin
Given card sedang expanded
When user melihat expanded area
Then tampil: badge jenis dengan icon, unit (jika Baru) atau akun_tujuan (jika Transfer),
     tanggal lengkap format EEEE dd MMMM yyyy, keterangan full text,
     tombol Ubah + Hapus (hanya untuk Bendahara)
  AND klik tombol Ubah/Hapus tidak bubble ke card onClick (e.stopPropagation)
  AND handleStartEdit memanggil setExpandedId(null) sebelum membuka form
```
