<objective>
## Goal
Implementasi Progressive Web App (PWA) dengan `vite-plugin-pwa`: service worker untuk offline caching, web app manifest agar app installable di browser/device.

## Purpose
SIKAT dipakai di lapangan — installable PWA memberikan akses cepat seperti native app, tanpa perlu app store. Offline caching menjaga UI tetap responsive meski koneksi lambat.

## Output
- `vite.config.ts` diupdate dengan `vite-plugin-pwa` config
- `index.html` dengan PWA meta tags
- Icons PWA di `public/` (192x192, 512x512)
- Service worker auto-generated oleh Workbox (cache static assets, network-first untuk `/api/*`)
</objective>

<task type="auto">
  <name>Task 1: Install vite-plugin-pwa dan konfigurasi vite.config.ts</name>
  <files>package.json, vite.config.ts</files>
  <action>
    **Install dependency:**
    ```bash
    npm install -D vite-plugin-pwa
    ```

    **Update `vite.config.ts`** — tambahkan VitePWA plugin:
    ```ts
    import { VitePWA } from 'vite-plugin-pwa';

    // Di dalam plugins array, tambahkan setelah tailwindcss():
    VitePWA({
      registerType: 'autoUpdate',
      includeAssets: ['favicon.ico', 'pwa-192x192.png', 'pwa-512x512.png'],
      manifest: {
        name: 'SIKAT - Sistem Kas Sekolah dan Talang',
        short_name: 'SIKAT',
        description: 'Aplikasi manajemen kas operasional dan dana talang sekolah',
        theme_color: '#ffffff',
        background_color: '#ffffff',
        display: 'standalone',
        start_url: '/',
        scope: '/',
        icons: [
          {
            src: 'pwa-192x192.png',
            sizes: '192x192',
            type: 'image/png',
            purpose: 'any'
          },
          {
            src: 'pwa-512x512.png',
            sizes: '512x512',
            type: 'image/png',
            purpose: 'any'
          },
          {
            src: 'pwa-maskable-512x512.png',
            sizes: '512x512',
            type: 'image/png',
            purpose: 'maskable'
          }
        ]
      },
      workbox: {
        globPatterns: ['**/*.{js,css,html,ico,png,svg,woff,woff2}'],
        runtimeCaching: [
          {
            urlPattern: /^\/api\//,
            handler: 'NetworkFirst',
            options: {
              cacheName: 'api-cache',
              networkTimeoutSeconds: 10,
              expiration: {
                maxEntries: 50,
                maxAgeSeconds: 300
              }
            }
          }
        ]
      },
      devOptions: {
        enabled: false
      }
    })
    ```

    Jangan ubah: config `server`, `resolve.alias`, plugins react() dan tailwindcss() yang sudah ada.
  </action>
  <verify>
    1. `npm run build` sukses tanpa error
    2. Di `dist/` ada file `sw.js` (service worker generated oleh Workbox)
    3. Di `dist/` ada file `manifest.webmanifest`
  </verify>
  <done>Partial AC-1, AC-2, AC-3: PWA plugin configured, service worker dan manifest akan di-generate saat build</done>
</task>

<task type="auto">
  <name>Task 2: Buat PWA icons dan update index.html</name>
  <files>public/pwa-192x192.png, public/pwa-512x512.png, public/pwa-maskable-512x512.png, index.html</files>
  <action>
    **Buat PWA icons di `public/`:**

    Gunakan script Node.js untuk generate icon placeholder PNG menggunakan Canvas API atau Sharp — atau buat icon SVG sederhana lalu convert. Karena tidak ada design tool, buat icon programatically:

    ```bash
    node -e "
    const { createCanvas } = require('canvas');
    // Jika canvas tidak tersedia, gunakan alternatif:
    // Buat file PNG minimal valid menggunakan Buffer
    "
    ```

    Alternatif yang lebih praktis — buat script `scripts/generate-icons.mjs`:
    ```js
    // Gunakan sharp jika tersedia, atau fetch placeholder dari placehold.co
    // Jika tidak ada tool, buat 1x1 PNG transparan sebagai placeholder
    // kemudian user dapat replace dengan icon asli setelah deploy
    ```

    **Pendekatan pragmatis untuk icons:**
    Jika tidak ada tool image manipulation yang tersedia:
    1. Cek apakah ada favicon.ico atau icon existing di public/
    2. Cek apakah `sharp` package tersedia (`npx sharp-cli --help`)
    3. Jika tidak ada, buat script `scripts/generate-icons.mjs` yang menggunakan fetch ke `https://via.placeholder.com/192` dan simpan ke `public/pwa-192x192.png`
    4. Jalankan script: `node scripts/generate-icons.mjs`
    5. Verifikasi file PNG terbuat di public/

    **Update `index.html`** — tambahkan PWA meta tags di `<head>`:
    ```html
    <meta name="theme-color" content="#ffffff">
    <meta name="mobile-web-app-capable" content="yes">
    <meta name="apple-mobile-web-app-capable" content="yes">
    <meta name="apple-mobile-web-app-status-bar-style" content="default">
    <meta name="apple-mobile-web-app-title" content="SIKAT">
    <link rel="apple-touch-icon" href="/pwa-192x192.png">
    ```

    Tambahkan setelah `<meta charset="UTF-8">` yang sudah ada.
    Jangan hapus meta tags yang sudah ada.
  </action>
  <verify>
    1. `ls public/pwa-192x192.png public/pwa-512x512.png` — file ada
    2. `npm run build` sukses
    3. `cat dist/manifest.webmanifest` menampilkan JSON dengan icons array berisi 3 entries
    4. `grep "theme-color" index.html` — meta tag ada
  </verify>
  <done>Partial AC-1: Icons dan meta tags tersedia, manifest.webmanifest valid dengan icons</done>
</task>
