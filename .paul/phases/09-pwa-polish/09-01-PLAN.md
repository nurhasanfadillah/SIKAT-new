<objective>
## Goal
Add 3 critical PWA UX features: offline fallback page, update notification toast (useRegisterSW), and custom install prompt (beforeinstallprompt).

## Purpose
Current PWA lacks user-facing signals for: (1) what happens when offline, (2) when a new version is available, (3) explicit install invitation. These gaps reduce PWA adoption and user trust.

## Output
- `public/offline.html` — offline fallback page with SIKAT branding
- `src/components/ReloadPrompt.tsx` — toast notifikasi "New version available"
- `src/components/InstallPrompt.tsx` — custom install button dengan `beforeinstallprompt`
- `vite.config.ts` — tambah `offlineFallback` + `navigateFallback` di workbox
- `src/App.tsx` — integrasi ReloadPrompt + InstallPrompt
</objective>

<acceptance_criteria>

## AC-1: Offline fallback
```gherkin
Given user is offline AND the requested page is not in SW cache
When user navigates to any route
Then a branded SIKAT offline page is shown with "Anda sedang offline" message + retry hint
```

## AC-2: Update notification
```gherkin
Given a new version of the app has been deployed
When user opens the app with the old SW cache
Then a toast appears: "Versi baru tersedia" with a "Refresh" button
And clicking Refresh triggers updateServiceWorker(true) which reloads the page
```

## AC-3: Custom install prompt
```gherkin
Given the app is PWA-installable AND user has not installed yet
When beforeinstallprompt event fires
Then a floating install button appears (positioned fixed bottom-right, non-intrusive)
And clicking it triggers prompt() which opens the native install dialog
And dismissed → button hides after first dismissal per session
```
